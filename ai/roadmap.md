# Roadmap

Deadline: **26 October 2026**. Order below is the build order; features 1–4 make the site shippable, 5–6 make it correct.

- **Status**: completed
- **Goal**: A working Next.js shell — tokens, typography, header, footer, metadata, 404 — with every page reachable, building static locally. Deploy tracked in feature 6.

## 2. Home page
- **Status**: completed
- **Goal**: The 30-second page: name, role line, three proof points, and a single CV/email call to action.

## 3. Work page
- **Status**: completed
- **Goal**: The five selected projects rendered from the typed content module, with role, period, context, output and outcome.

## 4. About page
- **Status**: completed
- **Goal**: Practice and education, all 18 verified credentials grouped into four areas, publications, and location/availability context.

## 5. Content pass
- **Status**: pending
- **Goal**: Replace every placeholder with verified copy and real assets — outcome numbers, CV PDF, headshot, testimonials, degree institution and years.

## 6. Launch polish
- **Status**: in development
- **Goal**: Production-ready and live on petlongdakhling.site: social preview, sitemap, accessibility and contrast audit, performance check, mobile pass.
